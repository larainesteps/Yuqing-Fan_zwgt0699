# PMC-Patients data — attribution and licence

## Source

The case narratives in this directory are derived from:

> Zhao, Z., Jin, Q., Chen, F., Peng, T. and Yu, S. (2023). 'A large-scale dataset of patient
> summaries for retrieval-based clinical decision support systems', *Scientific Data*, 10,
> article 909. https://doi.org/10.1038/s41597-023-02814-8

The PMC-Patients summaries are extracted from **PubMed Central open-access articles**. The
authors restrict the corpus to articles carrying **at least a CC BY-NC-SA licence** from the
PMC Open Access subset.

## Licence — read before adding a repository licence

The upstream terms are **CC BY-NC-SA** (Attribution – NonCommercial – ShareAlike):

| Term | Consequence here |
|---|---|
| **BY** — attribution | Zhao et al. (2023) must be credited wherever these files travel. |
| **NC** — non-commercial | These files may be used for research and teaching, not commercially. |
| **SA** — share-alike | Derivatives must carry the same licence. |

**ShareAlike applies to the derived files in this directory**, not to the rest of the
project. If a repository-wide licence is added later, it must not purport to relicense these
files — a permissive licence such as MIT applied repository-wide would conflict with the
NonCommercial and ShareAlike terms. Keep this directory's licence stated separately.

## Files

| File | Contents |
|---|---|
| `pmc-surgical-1000.jsonl` | 1,000 surgical case narratives selected from PMC-Patients |
| `pmc-surgical-extractions-rules.jsonl` | Structured records produced from those narratives by the local rule engine |
| `pmc-surgical-annotations-200.csv` | Annotation template over 200 of the narratives. Every `note_text` is populated; **every `gold_*` column is empty.** |

## The annotation template is not a benchmark

`pmc-surgical-annotations-200.csv` was generated by `services/nlp_service/annotations.py` as
a template for clinical annotation that was never carried out. It contains no ground truth.
Extraction accuracy on these narratives is therefore **unmeasured** — see Section 5.7 of the
report, and Section 6.2, which makes constructing an annotated benchmark the first item of
further work.

No narrative in this directory was sent to an external model provider; the rule engine ran
locally.
